# app-ads.txt for mutabloom.com
#
# Advertising networks crawl this file to confirm that whoever is selling advertising inside
# Mutabloom is actually allowed to. Without a verified file the better-paying programmatic
# demand does not bid, and an unverified file now means limited serving rather than merely
# lower prices, so this is a launch blocker rather than an optimisation. It is also the single
# biggest lever on launch-week revenue that is not code.
#
# THIS FILE IS COMPLETE AND READY TO DEPLOY. It held only OWNERDOMAIN until 2026-09-17, because
# until then no AdMob app existed and so no publisher ID could be authorised. Mutabloom was added
# to AdMob that day as app ca-app-pub-5706069574815967~1321980592, and the Google line below was
# copied from AdMob's own "Set up app-ads.txt" dialog rather than typed or adapted from anywhere
# else.
#
# A NAME WAS REMOVED FROM THIS COMMENT ON 2026-09-20 and it is worth saying why, because the
# temptation to put it back is real. The line used to note which other property of the publisher
# shares this account. README.md forbids naming the owner's other games anywhere on this domain,
# and this file is the worst possible place to break that rule: it is served from the root as
# text/plain, HTTP 200, and ad networks are guaranteed to fetch it. README.md's own cautionary
# tale is this exact shape -- on another property, the checked-in list of words a lint existed to
# keep off the site was itself published as prose on the domain the store listing pointed at.
# A comment in a crawled file is public writing.
#
# Do not type a seller line, and do not guess one: a wrong DIRECT line authorises a seller that
# is not used, which is worse than a missing one, because it looks verified and is not, and it is
# a supply-chain claim that is untrue.
#
# The same rule holds for every other network. Add a line only when that network is genuinely
# enabled in the shipping build. Mutabloom v1 runs on Google AdMob alone with no mediation
# (MUTABLOOM_PLAN.md section 11: "AdMob bidding only at first; mediation partners after
# ~1k DAU"), so when mediation does arrive, each partner's lines get pasted from that
# partner's own dashboard at the point the partner is switched on -- not in advance.
#
# Serving requirements, which are not negotiable: root of the domain set as the App Store
# Connect Marketing URL, text/plain, HTTP 200, no redirect to anywhere else. The crawl walks
# from the store listing to the domain, so it cannot even begin until both the listing and
# this site are live. Allow about 24 hours after that.
